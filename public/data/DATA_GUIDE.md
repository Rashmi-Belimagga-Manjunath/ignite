# IGNITE — Synthetic Business Data (`data/`)

This folder holds the **synthetic business dataset** for **Mori Coffee**, the demo client of the
IGNITE venture studio. It is generated by `npm run seed` (script: `scripts/seed.mjs`) and mirrors
`public/ignite.db` — the real SQLite database the agents query at runtime.

The assignment requires synthetic data to live in a *real, queryable source* and be *fetched at
query time*. It does: the agents run SQL against `ignite.db` in the browser (via sql.js WASM)
every single run. These exports exist so the data can be inspected directly in the repo.

## Files

| File | Table | Rows |
|---|---|---|
| `ignite.db` | the SQLite database (all 7 tables) | — |
| `business_profile.json/.csv` | brand identity, budget, capacity | 1 |
| `products.json/.csv` | menu items with real cost / price / margin | 7 |
| `inventory.json/.csv` | stock on hand with units | 10 |
| `operations.json/.csv` | pop-up cost structure | 1 |
| `brand.json/.csv` | voice, values, campaign concept | 1 |
| `locations.json/.csv` | 5 candidate pop-up sites with co-ordinates | 5 |
| `historical_sales.json/.csv` | 90 days of daily sales (262 rows, ~€34k revenue) | 262 |

## Schema

| Table | Columns |
|---|---|
| `business_profile` | `id, business_name, category, tagline, budget, currency, target_customer, staff_available, max_capacity, avg_order_value, opening_hours, home_base` |
| `products` | `id, name, description, cost, price, margin, category, hero` |
| `inventory` | `id, item, category, quantity, unit, notes` |
| `operations` | `id, area, permits_cost, insurance_cost, wifi_tether_cost, generator_cost, delivery_cost, marketing_budget, misc_cost` |
| `brand` | `id, tone, brand_values, audience, visual_identity, campaign_concept` |
| `locations` | `id, name, district, latitude, longitude, footfall_estimate, weekend_notes` |
| `historical_sales` | `id, date, product, units, revenue, location, weather, notes` |

## Reproducibility

The seed is fully deterministic (seeded PRNG), so `npm run seed` always produces the same dataset.

- `npm run seed` — rebuild `public/ignite.db` + these exports.
- `npm run sync:public` — copy these exports (and the docs) into `public/` so the live site can
  serve them on the **Log** page.
